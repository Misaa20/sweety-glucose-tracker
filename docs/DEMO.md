# Optional 2–3 minute demo walkthrough

Screenshots are already included and satisfy the assignment's visual submission requirement. If recording a demo, start the database and app using the README and run the seed once.

1. **0:00–0:25 — Authentication:** show the login page, mention the demo account, and log in with `demo@sweety.local` / `SweetyDemo123!`.
2. **0:25–0:55 — Record a reading:** point out the four slots. Add today's after-dinner reading. First submit an empty value and then a value of 39 to show validation. Save a valid value such as 128.
3. **0:55–1:20 — Edit and delete:** edit that new reading to 130, then delete it after confirming. Show the daily summary updating after each change. This restores the demo to its original three readings.
4. **1:20–1:55 — Reports:** open Reports & trends. Explain daily, month-to-date and previous-month boundaries. Change the date and show the averages, counts, highest/lowest values and chart. Expand the chart data table.
5. **1:55–2:15 — History:** open My readings, move between pages and point out the edit/delete controls.
6. **2:15–2:45 — Ownership and mobile:** log out, register a separate account, and show its empty journal. Resize the window or use browser mobile emulation to show the responsive dashboard.

Keep the repository README visible at the end to show installation, database setup, tests and assumptions. Do not show your `.env` or any private credentials in the recording.
